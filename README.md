# 知华委外加工管理

> 供应商手里的材料与应付加工费，一起对清。

由 [知华科技（上海如静知华信息科技有限公司）](https://www.zhuatech.cn/) 提供的 Java + H5 前后端分离企业软件社区源码版，数据库为 MySQL。

## 从单据到结果

供应商与原料建档 → 加工订单审批 → 发出原料 → 分批检验收货 → 自动扣耗与加工费计提 → 付款/退料 → 结清

按订单的单位用料定额控制发料上限，检验收货同时核销供应商在外原料；合格数量计提加工费，不合格数量扣耗但不计费。支持分批收货和分次付款，超收、超付、余料未处理均会阻止结案。

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 加工供应商 | 供应商、联系人与质量准入 | 暂停合作、恢复合作 |
| 原料库存 | 库存初始化后仅能通过流水调整 | 补充原料入库 |
| 委外订单 | 用料定额、发料余额、收货与结算 | 审批下达、发出原料、退回余料、核对结清、作废 |
| 加工收货 | 区分合格与不合格数量并自动扣耗材料 | 验收入库 |
| 材料流水 | 发料、扣耗、退料和成品入库数量 | 业务动作自动生成、查询、追溯、导出 |
| 加工费结算 | 合格收货计价与付款上限校验 | 审核付款 |

## 工程与验证

- 后端：Java 21 / Spring Boot 4.0.7 / JDBC / Flyway / MySQL 8.4，包名 `cn.zhuatech.subcontract`。
- 前端：Vue 3 / Vite / 原生 CSS，自适应桌面与移动端，业务端和管理端共用经鉴权的后端 API。
- 支持事务内多记录更新、乐观版本、幂等键、权限控制、提交审批分离、附件摘要、审计快照及 CSV 导出。

### 明确的功能边界

一期为单原料、单成品的委外订单，支持多批收发和合格/不合格拆分；不含多层 BOM、联副产品、复杂税务或总账过账。成品入库以数量流水记录，不是完整仓库作业系统。

这是一套可运行、带业务测试的初版实现；测试通过不等于完成了所有生产环境的容量、安全、监管或现场验收。上线前需结合真实数据、业务制度和基础设施进行实施验证。
